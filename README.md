# ADAPT

ブラウザだけで動く、個人用の健康・栄養記録アプリです。記録はブラウザのローカルストレージに保存され、外部サーバーへは送信されません。

## 起動方法

`index.html` をブラウザで開くだけで使えます。GitHub Pages などの静的サイトホスティングにも、そのまま公開できます。ローカルのWebサーバーで開く場合は、このフォルダで次を実行します。

```sh
python3 -m http.server 8080
```

その後、`http://localhost:8080` を開いてください。

## 含まれる機能

- 体重・体脂肪・カロリー・PFC・活動・水分・周期と症状のデイリー記録
- 就寝・起床・ベッドにいた時間・主観的な睡眠の質・任意の中途覚醒回数、目標との差分
- 食品ごとのグラム計算と、ルールベースの透明な栄養質問プロトタイプ
- 体重推移、睡眠・記録のふり返り、将来のグループ機能モック
- 目標設定、JSONデータ書き出し、端末内データの削除

## 制限

食品値は内蔵した少数の目安データであり、商品や調理法の差を反映しません。正確な確認にはアプリ内リンク先の[文部科学省 食品成分データベース](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_01110.html)を利用してください。栄養質問欄はAIではなく、食品名・グラム数・栄養項目を検出する単純な計算です。

本アプリは医療的な診断、睡眠評価、個別の減量指示を行いません。HealthKit、Google Fit、クラウド同期、外部AI接続は含みません。

## GitHub Pages での公開

1. GitHub で新しい **Public** リポジトリを作成します（例：`adapt-health`）。
2. このフォルダのファイルをリポジトリへアップロードします。
3. リポジトリの **Settings → Pages** を開き、`Deploy from a branch`、`main`、`/(root)` を選んで保存します。
4. 数分後に表示される `https://<ユーザー名>.github.io/adapt-health/` が公開URLです。

公開されるのはアプリのコードだけです。利用者の健康記録は、それぞれのブラウザ内に保存され、GitHubには送信されません。
